# The Banya Lab — чеклист сбора данных

Статус на 2026-09-02: каркас поднят, данные не собраны.
`npm run build` падает и печатает список незаполненных полей — это и есть живой чеклист.

**Закрыто бренд-документами владельца:** услуги и форматы, цены, минимум сессии,
тексты, тон, палитра, типографика, правила фото, 5 страниц-ответов.

**Осталось получить от владельца** — всё, что ниже без галочки.

## 1. Бизнес
- [ ] Название **точно как в Google Business Profile** (символ в символ)
- [ ] Телефон, по которому реально отвечают. Он же в GBP?
- [ ] Адрес: показывать на сайте или скрыть (service-area business)?
- [ ] Часы работы по дням
- [ ] Есть ли срочный / вне графика приём
- [ ] Зона обслуживания: районы Оаху или zip-коды
- [ ] С какого года работает

## 2. Услуги
- [ ] Список услуг **словами Максима**, не отраслевыми терминами
- [ ] Что из этого срочное / приоритетное
- [ ] Показываем ли цены. Если да — якорная цена «от», без полного прайса
- [ ] На каждую услугу: 2–4 предложения, что человек реально получает

## 3. Доверие
- [ ] Лицензии: номера **и даты истечения** (CI падает на просроченной)
- [ ] Сертификации
- [ ] Страховка, bond
- [ ] Ссылка на Google Business Profile и на отзывы
- [ ] **12 настоящих фото** — список кадров и требования в `docs/PHOTOS.md`
- [ ] **5 реальных вопросов**, которые задают клиенты — своими словами, не выдуманные

## 4. Техническое
- [ ] Домен: выбрать имя. **Регистрируем на владельца бизнеса**, доступ мне — до первой строчки кода
- [ ] Аккаунт Cloudflare на владельца
- [ ] Telegram chat id для уведомлений
- [ ] Email для дублей заявок

## Красные флаги
- Домен на прошлом подрядчике без доступа → решать до старта
- Рейтинг / отзывы / лицензии / «10 лет на рынке», которых нет → не пишем
- Стоковые фото людей → не используем

## Решения, принятые заранее
- Тип JSON-LD: `HealthAndBeautyBusiness` (баня/спа)
- Форма: имя, телефон, что нужно. Zip — опц. Email у клиента не спрашиваем
- Телефон кликабельный и виден без прокрутки, в том числе на мобильном
- Уведомления: Telegram + email, два независимых канала. Базы нет
- Turnstile не ставим, пока не появится спам
