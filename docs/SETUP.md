## Статус

Каркас готов, данные не собраны. `npm run build` **намеренно падает** на
незаполненных полях `client.json` — это защита от выкатки сайта с дырами.
Список того, чего не хватает, печатает сама сборка.

## 3. Cloudflare: второй сайт на том же аккаунте

На аккаунте уже висит taigayaga.com на бесплатном тарифе. **Он не пострадает.**
Домены на Cloudflare — независимые зоны, практического лимита на их число
на бесплатном тарифе нет, и добавление второго ничего не меняет в первом.
Сайты живут отдельными проектами Pages со своими сборками и переменными.

Лимиты бесплатного тарифа против нашего расхода:

| Лимит | Бесплатно | Нам нужно |
|---|---|---|
| Сборок в месяц (на аккаунт) | 500 | десятки, вместе с taigayaga |
| Параллельных сборок | 1 | 1 |
| Своих доменов на проект | 100 | 2 (apex и www) |
| Файлов в сайте | 20 000 | около 50 |
| Размер файла | 25 МиБ | самый тяжёлый ~200 КБ |
| Запросов к функции формы | 100 000 в сутки (квота Workers) | десятки |
| Процессорное время на вызов | 10 мс | две сетевые отправки, счёт не идёт |

Единственный общий на аккаунт счётчик — 500 сборок в месяц. Два сайта его
не заметят.

### 3.1 Добавить домен

Cloudflare → **Add a site** → `thebanyalab.com` → тариф **Free**.
Cloudflare просканирует существующие записи и выдаст два своих неймсервера.

У регистратора, где куплен домен, заменить неймсервера на выданные.
Обычно расходится за минуты, иногда до суток. Пока не разошлось,
в Cloudflare зона висит как Pending.

### 3.2 Создать проект (Workers)

Мастера Pages в дашборде больше нет — почему переехали, записано в ТЗ 008.

Workers & Pages → **Create application** → **Import a repository** →
`spbperez/thebanyalab`. Дальше:

    Project name              thebanyalab
    Build command             npm run build
    Deploy command            npx wrangler deploy
    Path                      /

Раздел **Build variables**: `NODE_VERSION` = `22`. Без неё Cloudflare возьмёт
свою версию по умолчанию, а генератор писан под двадцать вторую.

API token мастер создаёт сам — «A new token will be created automatically».

Куда что уходит, описано в `wrangler.jsonc`: статика из `./site`, Worker
получает только `/api/lead`. Указывать output-папку в интерфейсе не нужно,
её читает wrangler из конфига.

**Сборка упадёт, пока в `client.json` есть незаполненные поля.** Это не
поломка, это защита: она печатает список того, чего не хватает. Первая
зелёная сборка = данные собраны.

### 3.3 Завести зону

Cloudflare → **Add a domain** → `thebanyalab.com` → тариф **Free**.
Cloudflare просканирует существующие записи и выдаст два своих неймсервера.

У регистратора, где куплен домен, заменить неймсерверы на выданные.
Обычно расходится за минуты, иногда до суток. Пока зона в статусе Pending,
сайт доступен по адресу `*.workers.dev`.

### 3.4 Домен: ничего не нажимать

Домены прописаны в `wrangler.jsonc` → `routes` с `custom_domain: true`.
Wrangler заводит их при деплое и сам создаёт DNS-записи. В панели Cloudflare
руками не трогать ничего: ни Custom Domain, ни DNS, ни Redirect Rules.

Редирект `www` → апекс живёт в `worker/index.js`: меняется хост, путь
и параметры сохраняются, отвечает 301. Почему в коде, а не правилом
в панели — ТЗ 012.

Единственное, что нужно от панели: зона `thebanyalab.com` должна быть
добавлена и активна (раздел 3.3). Это уже сделано.

### 3.6 Мелочи, которые забывают

SSL/TLS → **Full (strict)**. Edge Certificates → **Always Use HTTPS** — включить.

Проверить после: `http://www.thebanyalab.com/answers/why-a-venik/` должен
привести на `https://thebanyalab.com/answers/why-a-venik/` — тот же путь,
один переход, замок в адресной строке.

## 4. Переменные и почта

Pages → Settings → **Variables and secrets**, окружение Production
(и Preview, если хочется тестировать на превью-ссылках). Все пять — как
Secret, не как Plain text:

    TELEGRAM_BOT_TOKEN   от @BotFather
    TELEGRAM_CHAT_ID     id чата Максима (через @userinfobot)
    RESEND_API_KEY       resend.com, бесплатного тарифа хватает
    FROM_EMAIL           apply@thebanyalab.com
    OWNER_EMAIL          куда дублировать заявки

Resend попросит подтвердить домен: выдаст записи SPF (TXT), DKIM и обычно
DMARC. Добавляются в DNS зоны thebanyalab.com **с выключенным прокси**
(серое облако, DNS only) — оранжевое облако ломает почтовую проверку.

Без подтверждённого домена письма уходить не будут, и заявка останется
на одном канале. Это ровно тот случай, ради которого каналов два.

**Оба канала обязательны.** Без базы заявка живёт только в момент отправки:
если единственный канал упал, заявка потеряна и никто об этом не узнает.

## 4.1 Аналитика

Cloudflare Web Analytics → Add a site → thebanyalab.com. Для проекта Pages
счётчик включается сам, вставлять ничего не надо. Бесплатно, без кук,

## 5. Оплата и бронирование

Два продукта устроены по-разному, поэтому и каналы разные (ТЗ 013).

### Пирс — Square Appointments

Аккаунт на компанию владельца (нужен EIN и счёт компании), тариф **Plus,
$49/мес за локацию**. На Free нельзя требовать оплату при бронировании, а
именно она и решает исходную задачу — клиент хотел заплатить компании, а не
человеку в инстаграме. Premium ($149) нужен только для автосписания за
неявку; предоплата эту задачу закрывает и без него.

Statement descriptor выставить в `BANYA LAB` — именно это видит клиент в
выписке по карте. Онлайн-платёж стоит 2.9% + 30¢, то есть $3.20 с гостя.

Услуги — четыре, вместо «цена × количество»:

    Lab Session · 1 guest    $100    2 ч
    Lab Session · 2 guests   $200    2 ч
    Lab Session · 3 guests   $300    2 ч
    Lab Session · 4 guests   $400    2 ч

Плюс ресурс «баня» — иначе два гостя забронируют одно и то же время.

Окна открываются **узкие**: конкретные вечера, которые мастер действительно
держит, и минимум 24 часа до записи. **Здесь единственное место, где всё
может развалиться:** если владелец не ведёт в Square свои часы и блокировки,
календарь начнёт врать, а врущий календарь хуже отсутствующего. Если вести
его некому — честнее вернуть `booking.channel` в `apply`, сайт это умеет
без правок кода.

Отмены: полная предоплата, возврат за 48 часов и позже — нет. Правило
написано на `/book/` до кнопки, а не мелким шрифтом после.

Ссылка на страницу бронирования кладётся в `client.json` → `booking.url`, а
`booking.channel` переключается на `square`. До этого момента страницы
`/book/` не существует и кнопки «Book» на сайте нет — проверка №13 за этим
следит в обе стороны.

### Море — ссылка на оплату вручную

Календаря на выход в море нет и не будет: он зависит от ветра, света и
состояния лодки. Клиент присылает желаемую дату заявкой, мастер отвечает,
и уже подтверждённому гостю уходит ссылка на оплату (Stripe или Square
Invoice — сумма за группу, всё равно нужен человек). Ссылки кладутся в
`client.json` → `pay.links`, страница `/pay/` закрыта от индексации и не
стоит в меню.

Одна ставка на Lab-сессию, независимо от мастера: цена обновлена 2026-09-27,
раньше были две (Юра $175 / Макс $250). Второй ссылки на мастера быть не должно.
