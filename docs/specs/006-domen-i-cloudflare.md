## Зачем

Сайту нужен адрес и хостинг. Аккаунт Cloudflare уже используется под taigayaga.com
на бесплатном тарифе — надо убедиться, что второй сайт его не задевает.

## Что делаем

Домен `thebanyalab.com` куплен 2026-09-02, проставлен в `client.json`.

Зоны на Cloudflare независимы, практического лимита на их число нет.
Единственный общий на аккаунт счётчик — 500 сборок в месяц; два сайта его
не заметят. Функция формы считается в квоту Workers: 100 000 запросов в сутки.

Порядок и все значения — в `docs/SETUP.md`. Ключевое: `NODE_VERSION=22`,
build `npm run build`, output `site`, www редиректом на апекс (один канонический
адрес, иначе Google видит два сайта, а NAP в GBP указывает на один).

`site/` из репозитория убран — его собирает Pages. Держать сгенерированное
в git значит однажды поправить данные, забыть сборку и выкатить старое.

## Чего НЕ делаем

Не заводим A-записи руками (Pages создаёт их сам), не включаем прокси на
почтовых записях Resend, не платим за тариф.
